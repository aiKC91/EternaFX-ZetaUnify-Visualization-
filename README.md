## Introduction

EternaFX is a Python-based framework designed to visualize and animate multidimensional data by projecting 4D datasets into 3D space. The framework leverages libraries such as NumPy, Matplotlib, and SciPy to create interactive and visually appealing representations of complex data.

## Features

- Interactive 3D scatter plots
- Dynamic animations of 4D data projections
- Customizable visual effects using colormaps
- Basic interactivity through sliders and other widgets
